# SIVI Codelijsten Verzuim

Dit koppelvlak maakt gebruik van de centrale **SIVI Codelijst Verzuim (Release 2026)**.

---

## 1. Codelijst Meldingstypen
| Code | Omschrijving | Betekenis |
|:---|:---|:---|
| `01` | Eerste verzuimdag | Initiële melding van arbeidsongeschiktheid |
| `02` | Gedeeltelijk herstel | Wijziging in het percentage werkhervatting |
| `03` | Volledig herstel | 100% hervatting van de overeengekomen uren |
| `04` | Correctie | Wijziging van een eerder ingezonden datum of gegeven |
| `09` | Administratieve intrekking | Melding was ten onrechte ingediend |

---

## 2. Codelijst Vangnetbepalingen
| Code | Omschrijving |
|:---|:---|
| `01` | Orgaandonatie |
| `02` | Zwangerschap en bevalling |
| `03` | No-riskpolis (Doelgroepregister / WIA-verleden) |
| `99` | Geen vangnet van toepassing |

---

## 3. Codelijst Verzuimstatussen
| Status | Toelichting |
|:---|:---|
| `Aangemeld` | Bericht ontvangen en initieel gevalideerd |
| `InBehandeling` | Dossier geopend en overgedragen aan casemanager |
| `WachtOpInformatie` | Aanvullende gegevens opgevraagd |
| `Afgerond` | Dossier gesloten na volledig herstel of wachttijdeinde |
